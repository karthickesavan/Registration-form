
# Registration Form with Real-Time Validation

## Project Description
A simple registration form built using HTML, CSS, and JavaScript. It validates user input in real time and enables the Register button only when all fields are valid.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Name validation: Ensures the name field is not empty.
- Email validation: Checks whether the email address has a valid format.
- Password validation: Requires a minimum of 6 characters.
- Real-time validation: Displays error messages while the user types.
- Disabled submit button: The Register button remains disabled until all fields are valid.
- Success message: Displays a confirmation message after successful validation.
- Responsive layout: Provides a simple, clean interface.

## How to Run the Project

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Enter your name, email address, and password.
5. Correct any validation errors.
6. Click Register when all fields are valid.

## Validation Rules

| Field | Validation Rule |
|---|---|
| Name | Cannot be empty |
| Email | Must have a valid email format |
| Password | Must contain at least 6 characters |

## Expected Output

- Error messages appear when input is invalid.
- The Register button stays disabled until all fields are valid.
- A registration success message appears after submission.
